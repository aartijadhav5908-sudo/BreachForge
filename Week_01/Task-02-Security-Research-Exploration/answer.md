# DAY 02 — SECURITY RESEARCH EXPLORATION

## Selected Technology : 
**Wi-Fi**

## What Is It?
It is a wireless network technology which connects multiple devices like mobiles, computers, tablets, IoT devices to the local network and internet using radio waves without physical cables.

## What Is It Mainly Used For?
Wi-Fi is mainly used for connecting multiple devices to the internet wirelessly within homes, offices, labs, libraries and public places. It avoids physical ethernet cables use and allows multiple devices to access the local network and the services. It is used for media streaming, internet access, smart home automation, file sharing & printing and communication.

## Security Features :
1. WPA3 (Wi-Fi Protected Access 3)
2. AES (Advanced Encryption Standard)
3. SAE (Simultaneous Authentication of Equals)

## One Security Feature Explained :
1. WPA3 (Wi-Fi Protected Access 3) - WPA3-Personal uses SAE (Simultaneous Authentication of Equals), which provides stronger authentication and improves protection against password-guessing attacks. This helps make Wi-Fi connections more secure and protects the network from unauthorized access.

## Security Resource :
1. NIST - Guidelines for Securing Wireless Local Area Networks (WLANs)
2. NIST - Wireless Intrusion Detection and Prevention System (WIDPS). 
3. Wi-Fi Alliance — Wi-Fi CERTIFIED WPA3

## What I Learned :
I learned that Wi-Fi is not only about providing internet access; it also includes security features to protect wireless connections, connected devices, and user data. WPA3 and SAE help improve Wi-Fi security and reduce security risks that can arise in wireless networks. I also learned that Wi-Fi security involves both encryption and authentication to help protect connections from unauthorized access.
