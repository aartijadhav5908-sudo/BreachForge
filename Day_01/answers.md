## Selected Research Area
Threat Intelligence

## What Is It ?
Threat Intelligence means collecting, processing and analyzing information about the threats to understand the threat method, attackers motives and targets.

## Common Security Problems
### 1. Software Holes
   The common error or bug in the software that gives access to the attackers easily and that can leak the data of the organizations.
### 2. Human Tricks or Social Engineering Attacks
   Emails or messages that pretend to be official to the users and let them redirect to fake applications to steal the user credentials.
### 3. Zeero-day Vulnerability
   The error or bug present in the computer program that unknown to the vendors and coders which can be exploit by attackers.

## Tools & Resources
### 1. MITRE ATT&CK Matrix
   The open source encyclopedia that provides exact techniques, tactics and procedures that real-world attackers use to do attacks.
### 2. VirusTotal
   A free website where users can upload links and files to scan them by over 70+ different antivirus programs and website scanners at same time.
### 3. Sandboxes
   A safe, isolated digital environments where researchers can open malware and watch it run without risking actual computer harm.

## Public Research Example
**What was researched?**

This report investigated a real cyberattack where attackers used BumbleBee malware to get into a company network and eventually deploy Akira ransomware.

**What was discovered or investigated?**

Researchers investigated how the attackers used a fake software download appearing in Bing search results. The fake installer delivered BumbleBee, which helped the attackers access the network, move between systems, steak credentials and data, and prepare the environment for ransomware.

**What was the Security Impact?**

The attackers stole more than 75 GB of data and finally deployed Akira ransomware, which encrypted systems and disrupted the organization's infrastructure.

**What did I found interesting?**

I found it interesting that the attack started with a fake software download from a search result. It shows that even a normal-looking software search can become an entry point for a serious cyberattack.

## What I Found Interesting?

I found it interesting that Threat Intelligence can help researchers understand an attack by studying the attacker's methods, malware, infrastructure, and activities.
