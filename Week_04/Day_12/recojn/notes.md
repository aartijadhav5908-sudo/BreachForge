# Recon Notes

## Target

webgoat.local:8080

## Nmap

8080/tcp was identified as open HTTP with Apache Tomcat.

## Burp

Burp HTTP History captured requests from the WebGoat application.

## Application

The application contains authentication, lessons, challenges, service endpoints, JSON resources and API-style routes.

## Security Note

Passwords, session cookies, tokens and personal information were excluded from the final submission.

## Scope

All reconnaissance was performed against the authorized local WebGoat lab.
