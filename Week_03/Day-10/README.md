# Day 10 — Security Research Puzzle Challenge
## Part 1 — Connected Security Concerns
After reviewing all the clues, I found two main security concerns.
1. Former Employee Account
- An employee left the company two months ago.
- The employee's company account is still present in the account list.
- The account previously had access to internal resources.
- Recent login activity has not been checked.
- No account review has been performed recently.  

These clues are connected to account security and access control. The main concern is that an old employee account may still have access, but this has not been verified yet.

2. Publicly Shared Internal File
- An internal file was shared using a public link.
- The file contains company information.
- The link was created several months ago.
- Shared-file permissions have not recently been reviewed.
- The company does not currently know who accessed the file.

These clues are connected to information exposure and access control. The main concern is that company information may have been accessible to people who were not supposed to access it.

## Part 2 — Case Summary
The available information shows that the company has not recently reviewed some important access controls.  

One former employee's account is still listed even though the employee left the company two months ago. The account previously had access to internal resources, but recent login activity has not been checked.

There is also an internal file that was shared through a public link. The file contains company information, and the link was created several months ago. The company has not recently reviewed the permissions or checked who accessed the file.

These facts show areas that should be reviewed. However, there is not enough information to say that the former employee accessed the systems or that the file was accessed by an unauthorized person.

## Part 3 — Confirmed Facts
The following information is directly given in the case:
1. An employee left the company two months ago.
2. The employee's company account still appears in the account list.
3. The account previously had access to internal resources.
4. Recent login activity has not been checked.
5. No recent account review has been performed.
6. An internal file was shared using a public link.
7. The file contains company information.
8. The public link was created several months ago.
9. Shared-file access permissions have not recently been reviewed.
10. The company currently does not know who accessed the shared file.

## Part 4 — Unknown Information
The following information is not known from the available clues:
1. Whether the former employee's account is still active.
2. Whether the former employee logged in after leaving the company.
3. Whether the account was actually used after the employee left.
4. What internal resources the account can currently access.
5. Whether the account has been disabled or its permissions removed.
6. Who created the public file-sharing link.
7. Who accessed the shared file.
8. When the shared file was accessed.
9. Whether anyone outside the company accessed the file.
10. Whether the information in the file was actually downloaded or copied.

These points would need to be checked before making further conclusions.

## Part 5 — Research Questions
Before making any further conclusions, I would investigate these questions:
1. Is the former employee's account still active?
2. Has the account been used after the employee left the company?
3. What internal resources can the account currently access?
4. Has the former employee's access been removed or disabled?
5. Who created the public link for the internal file?
6. Who has accessed the file through the public link?
7. When was the file last accessed?
8. Is the public link still active?
9. Can the link be accessed by anyone with the link?
10. Has any company information been downloaded or shared further?

## Part 6 — Evidence Checklist
I would review the following information to verify the concerns:
### Account Security
- Employee account status
- Account creation and deactivation records
- Recent login history
- Login timestamps
- Access permissions
- Internal resource access records
- Employee offboarding records
### File Sharing
- File-sharing settings
- Public link settings
- Link creation date
- File access logs
- User or account information from access logs
- Download or sharing activity
- Current file permissions
This information would help confirm what actually happened without making assumptions.

## Part 7 — Priority Decision
### Priority: High
I would review the publicly shared internal file first.  
The reason is that the file contains company information and is available through a public link. The company also does not currently know who accessed it.  
The former employee account is also an important concern, but the available information does not confirm that the account was used after the employee left.

## Part 8 — Recommended Next Steps
The fictional organization should take these safe steps:
1. Review the former employee's account status.
2. Disable the account if it is no longer required.
3. Review and remove unnecessary access permissions.
4. Check login activity after the employee's departure.
5. Review the public link settings for the internal file.
6. Restrict the file so that only authorized users can access it.
7. Review file access logs to identify who accessed the file.
8. Check whether the file was downloaded or shared further.
9. Perform a wider review of old employee accounts.
10. Regularly review shared-file permissions and public links.

These steps can help the organization identify and reduce unnecessary access.
